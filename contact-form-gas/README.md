# お問い合わせフォームの受け取り設定（Google Apps Script）

サイトのフォームから送られた内容を、

1. Googleスプレッドシート「河野智也サイト お問い合わせ記録」に1行ずつ記録し
2. Gmail（heso.710.soul@gmail.com）に通知メールを送る

しくみです。通知メールに「返信」すると、そのままお客様のアドレスに返信できます。

このフォルダの中身はサイトには公開されません（`_config.yml` の `exclude` で除外しています）。

## 最初の設定（10分ほど・1回だけ）

1. Googleドライブで「河野智也サイト お問い合わせ記録」スプレッドシートを開く
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から入っている `function myFunction() {...}` を全部消して、このフォルダの `コード.gs` の中身を丸ごと貼り付け、保存（💾）
4. 上の関数の選択欄で `testNotify` を選んで「実行」
   - 「承認が必要です」と出るので、自分のGoogleアカウントを選んで許可します
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」
     （自分で作ったスクリプトなので問題ありません）
   - Gmailにテストメールが届き、シートにテスト行が入れば成功です（テスト行は消してOK）
5. 右上の「デプロイ」→「新しいデプロイ」
   - 種類の選択（⚙）で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押し、表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec`）をコピー
6. GitHubの `_config.yml` の `contact_endpoint: ""` の `""` の中にそのURLを貼り付けて保存
   - 数分でサイトに反映され、フォームから送れるようになります

## あとから変えたいとき

- **通知先のアドレスを変える**：`コード.gs` の `NOTIFY_TO` を書き換えて保存 →「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン：新バージョン」→「デプロイ」
  （この方法ならURLは変わらないので、`_config.yml` はそのままでOK）
- **フォームを一時的に止める**：`_config.yml` の `contact_endpoint` を `""` に戻す（旧Googleフォームが案内されます）

## 届かないときの確認

- 送信直後に「送信できませんでした」と出る → デプロイ時の「アクセスできるユーザー」が「全員」になっているか
- 通知メールが来ない → Gmailの迷惑メールフォルダ、Apps Script 画面左の「実行数」でエラーが出ていないか
- 同じアドレスから60秒以内の連続送信と、1日50件を超える送信は、いたずら対策のため受け付けません
